# KOV Interior

A responsive portfolio and inquiry website for KOV Interior, an Ahmedabad interior design studio. Built with Next.js App Router, TypeScript, and Tailwind CSS.

## Run locally

```bash
cd kov-interior
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Before presenting as a live business site

- Replace the illustrative project names and imagery with KOV's approved portfolio.
- Connect the inquiry form to the studio's preferred inbox or CRM. It currently demonstrates the interaction without sending or storing submitted details.
- Add confirmed contact details and social links when available.

## Local media

Images in `public/images` are locally bundled from Unsplash. The short looping interior clip in `public/videos/interior-film.mp4` is a Pexels stock video. The site respects reduced-motion preferences.
