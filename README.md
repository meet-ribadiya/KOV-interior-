# KOV Interior

A responsive, editorial-style website for KOV Interior, an Ahmedabad interior design studio. Built with Next.js App Router, TypeScript, Tailwind CSS, Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before presenting as a live business site

- Replace the illustrative design-study imagery and project details with KOV's approved portfolio.
- Connect the inquiry form to the studio's preferred inbox or CRM. It currently demonstrates the interaction without sending or storing submitted details.
- Add confirmed contact details and social links when available.

## Local media

Images in `public/images` are locally bundled from Unsplash. The short looping interior clip in `public/videos/interior-film.mp4` is a Pexels stock video. Motion effects respect reduced-motion preferences. Motion and Lucide provide lightweight, tree-shaken animation and icon components.
